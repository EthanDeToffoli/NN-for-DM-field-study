# NN-for-DM-field-study
Codes for my Padua University bachelor thesis: "A field level study of dark matter fluctuations field on non linear scales" \\
data_gen.py: creates lognormal fields using CAMB for P(k) and Powerbox for gaussian gen
models.py: a bunch of models tried (only some of them cited in the thesis)
training_loop.py: training loop for non-hybrid archs
training_loop_pk.py: training loop for hybrid archs
